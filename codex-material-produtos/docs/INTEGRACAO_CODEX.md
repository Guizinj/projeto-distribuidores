# Instrução de integração para a Codex

Este pacote foi preparado para a segunda rodada do projeto.

## O que fazer

- Copiar `assets/products/elure/` para o diretório equivalente do projeto.
- Copiar `assets/products/impactos/` para o diretório equivalente do projeto.
- Usar os dados de `data/products-elure.js` e `data/products-impactos.js` para substituir os produtos fictícios.
- Manter o schema e a camada `product-service` já existentes no projeto.
- Preservar integralmente o design atual dos cards, grid, home, catálogo e página de produto.
- Não alterar identidade comercial atual.
- Não criar preço, carrinho, checkout, login ou Supabase nesta rodada.
- Não inventar produtos adicionais.

## Importante sobre os assets

As imagens da Impactos foram extraídas do catálogo oficial fornecido.
As imagens da ÉLURE foram preparadas a partir do material fornecido pelo proprietário do projeto.

Não reutilizar uma imagem para representar produtos diferentes.

## Tipografia

Nesta mesma rodada, corrigir o carregamento real das fontes:
- Cormorant Garamond para títulos/editorial
- Inter para interface/corpo
